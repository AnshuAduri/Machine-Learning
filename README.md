K-Means vs DBSCAN Clustering Tutorial
A tutorial comparing K-Means and DBSCAN clustering algorithms on different types of data. The goal is to show when each algorithm works well and when it struggles.
Author: Anshu Aduri
What is covered
How K-Means clustering works
How DBSCAN clustering works
Testing both on three different synthetic datasets
Visual and quantitative comparison of results
When to pick one over the other
How to run
Install the dependencies first:
```
pip install -r requirements.txt
```
Then open the notebook:
```
jupyter notebook notebook.ipynb
```
Run all the cells top to bottom. The plots will be saved automatically in the `images/` folder.
Project structure
```
notebook.ipynb       - main notebook with all the code and explanations
README.md            - this file
LICENSE              - MIT license
requirements.txt     - python packages needed
images/              - plots generated by the notebook
data/                - datasets saved as csv files
```
What I found
K-Means works great when clusters are round and well separated
K-Means fails badly on non-convex shapes like crescents
DBSCAN handles weird shapes much better
DBSCAN can also detect noise points which K-Means cannot do
